# SOLYNTO Website

Static marketing site for SOLYNTO — an independent Nordic DSP for agencies buying programmatic media. Live at [solynto.com](https://solynto.com).

Plain HTML/CSS, no build step; the directory deploys as-is via GitHub Pages from `main` (`CNAME` pins the custom domain). All CTAs are `mailto:` links to `info@solynto.com`.

## Local preview

```bash
open index.html   # or: python3 -m http.server 8000
```
